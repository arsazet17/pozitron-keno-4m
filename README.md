# KENO FULL20 · RETIE · SPECIFICITY

Полностью новая архитектура вместо старого M4.

## Источник факта
`full20_stoloto_sync.py` получает со Столото и трижды сверяет:
- номер тиража;
- дату;
- время;
- 20 чисел **в порядке выпадения**;
- официальный `Столбец N`.

Если 3 чтения не совпали, запись не делается.

## Corrected tie-break
Официальный столб — источник истины. Одновременно приложение делает аудит: если несколько столбов имеют одинаковый максимум, побеждает тот, который раньше набрал весь максимальный счёт (позиция завершающего числа). При расхождении official/corrected sync останавливается.

## FULL20
Модель основана на corrected RETIE базе 32 231 тиражей. Используются все 20 чисел, без удаления чисел текущего столба. SCORE = сумма частот совпавших TOP-50 признаков размеров 1–10.

## Комбы
Для В1/В2/В3/R1/R2 фиксируется одна комба размеров 2–10 по specificity `support_S / support_ALL`, фильтр `support_S >= 8`.

## Anti-leakage
Строго: `FROZEN → ФАКТ → ПРОВЕРКА → ОБУЧЕНИЕ → НОВЫЙ FROZEN`.
Старый frozen никогда не переписывается.

## UI
Страницы: Главная, Прогноз, Тиражи FULL20, Архив прогнозов, Комбы по столбам, Настройки.
Старые 4M алгоритмы и старый интерфейс удалены.
