# KENO 4M

Отдельное приложение для прогноза столбов КЕНО по четырём методам:

- В/В — вертикальная цепочка → вертикальный поиск;
- В/Г — вертикальная цепочка → горизонтальный поиск;
- Г/В — горизонтальная цепочка → вертикальный поиск;
- Г/Г — горизонтальная цепочка → горизонтальный поиск.

## Логика прогноза

**Вариант 1 — основной прогноз:** три столба с максимальным охватом разных методов. При равенстве учитывается сила/длина рабочих цепочек, затем свежесть исторического подтверждения.

**Вариант 2:** один столб по общей частоте продолжений всех четырёх методов. При равенстве цепочки сокращаются слева и поиск повторяется.

**Доп. Г/Г:** один столб только по горизонтальной цепочке и горизонтальному поиску.

Если один столб входит в Вариант 1 и одновременно совпадает с Вариантом 2 и Доп. Г/Г, приложение выделяет его как главный согласованный акцент.

## Архив

Рабочий Excel: `data/keno_stolby_po_date_vremeni_16-08-2026.xlsx`.

Новые фактические результаты сохраняются локально на устройстве. Кнопка «Выгрузить Excel» формирует актуальную копию с внесёнными результатами.

2. Статистика
